# GPT-SoVITS TTS 테스트 가이드

## 개요

학습이 완료된 SoVITS + GPT 모델을 로드하여 텍스트로부터 음성을 합성(TTS)합니다.

```
모델 로드 → 참조 오디오 설정 → 텍스트 입력 → 음성 합성
```

## 실행 방법

```bash
python voice_service.py
```

브라우저에서 `http://127.0.0.1:7860` 접속 후 **TTS 테스트** 탭을 선택합니다.

---

## Step 1: 모델 로드

학습된 SoVITS 모델과 GPT 모델을 메모리에 로드합니다.

### 사용법

1. **모델 목록 새로고침** 버튼을 클릭하여 사용 가능한 모델 목록을 불러옵니다
2. 드롭다운에서 **SoVITS 모델**과 **GPT 모델**을 각각 선택합니다
3. **모델 로드** 버튼을 클릭합니다
4. 상태에 "모델 로드 완료!" 메시지가 표시되면 준비 완료

### 모델 파일 위치

| 모델 | 기본 경로 |
|------|-----------|
| SoVITS | `SoVITS_weights_v2/{실험이름}_e{에폭}_s{스텝}.pth` |
| GPT | `GPT_weights_v2/{실험이름}-e{에폭}.ckpt` |

> 같은 실험 이름의 SoVITS와 GPT 모델을 쌍으로 선택해야 합니다.

---

## Step 2: 참조 오디오 설정

TTS는 **참조 오디오**의 음색과 스타일을 기반으로 음성을 합성합니다. 참조 오디오는 합성 결과의 음색을 결정하는 핵심 요소입니다.

### 입력 항목

| 항목 | 설명 |
|------|------|
| **참조 오디오** | 음색의 기준이 되는 오디오 파일 (3~10초 권장) |
| **참조 오디오 텍스트** | 참조 오디오에서 말하는 내용을 텍스트로 입력 |
| **참조 오디오 언어** | 참조 오디오의 언어 선택 |
| **참조 텍스트 없이 사용** | 체크 시 참조 텍스트 없이 동작 (품질 저하 가능) |

### 참조 오디오 선택 팁

- **길이**: 3~10초가 적당합니다. 너무 짧으면 음색 파악이 어렵고, 너무 길면 불안정합니다.
- **품질**: 배경 소음이 없는 깨끗한 오디오를 사용하세요.
- **내용**: 참조 텍스트를 정확히 입력하면 합성 품질이 향상됩니다.
- **학습 데이터**: 학습에 사용된 오디오 중 일부를 참조 오디오로 사용하면 좋습니다.

### 언어 옵션

| 코드 | 언어 |
|------|------|
| `ko` | 한국어 |
| `zh` | 중국어 |
| `en` | 영어 |
| `ja` | 일본어 |
| `yue` | 광둥어 |
| `auto` | 자동 감지 |
| `auto_yue` | 자동 감지 (광둥어 포함) |

---

## Step 3: 텍스트 입력 & 합성

### 기본 입력

| 항목 | 설명 |
|------|------|
| **합성할 텍스트** | 음성으로 변환할 텍스트 입력 |
| **텍스트 언어** | 입력 텍스트의 언어 선택 |
| **속도** | 합성 음성의 재생 속도 (0.5x ~ 2.0x) |
| **시드** | 재현 가능한 결과를 위한 시드 값 (-1 = 랜덤) |

### 고급 파라미터

| 파라미터 | 범위 | 기본값 | 설명 |
|----------|------|--------|------|
| **Top K** | 1 ~ 100 | 15 | 토큰 샘플링 시 상위 K개만 고려. 낮을수록 안정적, 높을수록 다양함 |
| **Top P** | 0.0 ~ 1.0 | 1.0 | 누적 확률 기반 샘플링. 1.0이면 Top K만 적용 |
| **Temperature** | 0.0 ~ 2.0 | 1.0 | 샘플링 온도. 낮을수록 안정적이고 단조로움, 높을수록 다양하지만 불안정 |

### 사용법

1. 합성할 텍스트를 입력합니다
2. 텍스트 언어를 선택합니다 (한국어: `ko`)
3. 필요 시 속도, 시드, 고급 파라미터를 조정합니다
4. **음성 합성** 버튼을 클릭합니다
5. 합성 결과가 오디오 플레이어에 표시됩니다

---

## 파라미터 튜닝 가이드

### 음성이 불안정하거나 깨질 때

- Temperature를 `0.6 ~ 0.8`로 낮추기
- Top K를 `5 ~ 10`으로 낮추기
- 더 긴 참조 오디오(5~10초) 사용

### 음성이 너무 단조로울 때

- Temperature를 `1.2 ~ 1.5`로 높이기
- Top K를 `20 ~ 50`으로 높이기

### 재현 가능한 결과가 필요할 때

- 시드를 `-1`이 아닌 특정 숫자로 고정 (예: `42`)
- 같은 시드, 같은 파라미터, 같은 참조 오디오를 사용하면 동일한 결과를 얻을 수 있음

## 전체 사용 흐름 예시

```
1. TTS 테스트 탭 선택
       ↓
2. "모델 목록 새로고침" 클릭
       ↓
3. SoVITS 모델 선택 (예: my_voice_model_e8_s200.pth)
   GPT 모델 선택 (예: my_voice_model-e15.ckpt)
       ↓
4. "모델 로드" 클릭 → "모델 로드 완료!" 확인
       ↓
5. 참조 오디오 업로드 (학습 데이터 중 깨끗한 음성 하나)
   참조 텍스트 입력 (해당 오디오의 대사)
   참조 언어: ko
       ↓
6. 합성할 텍스트 입력
   텍스트 언어: ko
       ↓
7. "음성 합성" 클릭
       ↓
8. 결과 오디오 재생 및 확인
```

## 문제 해결

| 증상 | 원인 및 해결 |
|------|-------------|
| "먼저 모델을 로드하세요" | 모델 로드를 먼저 진행하세요 |
| "참조 오디오를 지정하세요" | 참조 오디오를 업로드하세요 |
| 합성 음질이 나쁨 | 참조 오디오 품질 확인, Temperature/Top K 조정, 학습 에폭 늘리기 |
| 합성 속도가 느림 | GPU 사용 확인, 텍스트를 짧게 나누어 합성 |
| 모델 목록이 비어 있음 | 학습이 완료되었는지 확인, "모델 목록 새로고침" 재클릭 |
