# GPT-SoVITS 음성 학습 가이드

## 개요

GPT-SoVITS 음성 학습은 5단계로 구성됩니다. 각 단계를 순서대로 진행해야 합니다.

```
오디오 슬라이싱 → 음성 인식(ASR) → 데이터셋 전처리 → SoVITS 학습 → GPT 학습
```

## 실행 방법

```bash
python voice_service.py
```

브라우저에서 `http://127.0.0.1:7860` 접속 후 **학습** 탭을 선택합니다.

### 실행 옵션

| 옵션 | 설명 | 기본값 |
|------|------|--------|
| `--port` | 서버 포트 | 7860 |
| `--host` | 서버 호스트 | 127.0.0.1 |
| `--share` | 외부 공유 링크 생성 | off |
| `--version` | 모델 버전 (v1/v2/v3/v4/v2Pro/v2ProPlus) | v2 |

---

## 사전 설정

학습을 시작하기 전에 상단의 **모델 버전 설정**을 먼저 입력합니다.

| 항목 | 설명 |
|------|------|
| **모델 버전** | v1, v2, v3, v4, v2Pro, v2ProPlus 중 선택. v3/v4는 VRAM을 더 많이 사용합니다. |
| **실험 이름** | 학습 결과가 저장될 이름. 영문/숫자 권장 (예: `my_voice_model`). |
| **GPU 번호** | 사용할 GPU 인덱스. 단일 GPU 환경에서는 `0`. |

> 실험 이름은 이후 모든 단계에서 공유됩니다. 한번 정하면 끝까지 동일한 이름을 사용하세요.

---

## Step 1: 오디오 슬라이싱

긴 오디오 파일을 짧은 구간으로 자동 분할합니다.

### 입력

| 항목 | 설명 |
|------|------|
| **입력 오디오 경로** | 원본 오디오 파일 또는 폴더 경로 |
| **출력 폴더** | 분할된 오디오 저장 위치 (기본: `output/slicer_opt`) |

### 파라미터

| 파라미터 | 범위 | 기본값 | 설명 |
|----------|------|--------|------|
| 음량 임계값 (dB) | -60 ~ 0 | -34 | 이 값보다 작은 구간을 무음으로 판단 |
| 최소 길이 (ms) | 1000 ~ 10000 | 4000 | 분할된 오디오의 최소 길이 |
| 최소 간격 (ms) | 100 ~ 1000 | 300 | 무음 구간의 최소 길이 |

### 사용법

1. 입력 오디오 경로와 출력 폴더를 지정
2. **슬라이싱 시작** 클릭
3. 상태에 "오디오 슬라이싱 완료!"가 표시되면 다음 단계로 진행

---

## Step 2: 음성 인식 (ASR)

슬라이싱된 오디오에서 텍스트를 자동 추출합니다.

### 입력

| 항목 | 설명 |
|------|------|
| **입력 오디오 폴더** | Step 1의 출력 폴더 (예: `output/slicer_opt`) |
| **출력 폴더** | ASR 결과 저장 위치 (기본: `output/asr_opt`) |

### 파라미터

| 파라미터 | 선택지 | 기본값 | 설명 |
|----------|--------|--------|------|
| ASR 모델 | Faster Whisper / 达摩 ASR | Faster Whisper (多语种) | 한국어는 Faster Whisper 사용 |
| 모델 크기 | medium / large-v2 / large-v3 / large-v3-turbo | large-v3 | 클수록 정확하나 느림 |
| 언어 | ko / ja / en / zh / auto | ko | 오디오의 언어 |
| 정밀도 | float16 / float32 / int8 | float16 | VRAM 절약 시 int8 사용 |

### 사용법

1. Step 1의 출력 폴더를 입력 오디오 폴더에 지정
2. 언어를 `ko`로 설정 (한국어의 경우)
3. **ASR 시작** 클릭
4. 완료 시 `.list` 파일이 생성됨 (예: `output/asr_opt/slicer_opt.list`)

### 결과물

ASR이 완료되면 `.list` 파일이 생성됩니다. 이 파일에는 각 오디오 파일과 인식된 텍스트가 매핑되어 있습니다. 필요 시 텍스트 에디터로 열어 오인식된 부분을 수동 교정할 수 있습니다.

---

## Step 3: 데이터셋 전처리 (1A+1B+1C)

텍스트 분석, HuBERT 특성 추출, 시맨틱 토큰 추출을 순차적으로 진행합니다.

### 입력

| 항목 | 설명 |
|------|------|
| **텍스트 리스트 파일** | Step 2에서 생성된 `.list` 파일 경로 |
| **오디오 폴더 경로** | Step 1의 출력 폴더 |

### 내부 처리 과정

| 단계 | 이름 | 설명 |
|------|------|------|
| 1A | 텍스트 분석 | 텍스트의 음소(phoneme)를 추출하고 BERT 특성 생성 |
| 1B | HuBERT 특성 추출 | 오디오에서 음성 특성 벡터를 추출 |
| 1C | 시맨틱 토큰 추출 | 사전학습 모델로 시맨틱 토큰 생성 |

### 사용법

1. 텍스트 리스트 파일과 오디오 폴더 경로를 지정
2. **전처리 시작** 클릭
3. 진행 상태가 순차적으로 표시됨 (1A → 1B → 1C)
4. "데이터셋 전처리 완료!" 메시지 확인

> v2Pro/v2ProPlus 버전 선택 시 1B 단계에서 SV(Speaker Verification) 추출이 추가로 진행됩니다.

---

## Step 4: SoVITS 학습

음성 합성의 핵심 모델인 SoVITS를 학습합니다.

### 파라미터

| 파라미터 | 범위 | 기본값 | 설명 |
|----------|------|--------|------|
| 배치 사이즈 | 1 ~ 40 | GPU VRAM에 따라 자동 설정 | 클수록 빠르지만 VRAM 더 필요 |
| 총 에폭 | 1 ~ 25 | v1/v2: 8, v3/v4: 2 | 전체 학습 반복 횟수 |
| 저장 간격 (에폭) | 1 ~ 25 | v1/v2: 4, v3/v4: 1 | 중간 체크포인트 저장 주기 |

### 사용법

1. 파라미터를 조정 (기본값으로도 충분)
2. **SoVITS 학습 시작** 클릭
3. 학습이 완료되면 모델이 `SoVITS_weights_v2/` 폴더에 저장됨

### 출력 모델 경로

버전에 따라 저장 위치가 다릅니다:
- v2: `SoVITS_weights_v2/{실험이름}_e{에폭}_s{스텝}.pth`

---

## Step 5: GPT 학습

텍스트에서 시맨틱 토큰을 예측하는 GPT 모델을 학습합니다.

### 파라미터

| 파라미터 | 범위 | 기본값 | 설명 |
|----------|------|--------|------|
| 배치 사이즈 | 1 ~ 40 | GPU VRAM에 따라 자동 설정 | 클수록 빠르지만 VRAM 더 필요 |
| 총 에폭 | 1 ~ 20 | 15 | 전체 학습 반복 횟수 |
| 저장 간격 (에폭) | 1 ~ 10 | 5 | 중간 체크포인트 저장 주기 |

### 사용법

1. 파라미터를 조정
2. **GPT 학습 시작** 클릭
3. 학습이 완료되면 모델이 `GPT_weights_v2/` 폴더에 저장됨

---

## 전체 워크플로우 요약

```
1. 원본 오디오 준비 (깨끗한 단일 화자 음성)
       ↓
2. [Step 1] 오디오 슬라이싱 → output/slicer_opt/
       ↓
3. [Step 2] ASR로 텍스트 추출 → output/asr_opt/*.list
       ↓
4. (선택) .list 파일을 열어 텍스트 교정
       ↓
5. [Step 3] 데이터셋 전처리 (1A+1B+1C)
       ↓
6. [Step 4] SoVITS 학습 → SoVITS_weights_v2/
       ↓
7. [Step 5] GPT 학습 → GPT_weights_v2/
       ↓
8. TTS 테스트 탭에서 결과 확인
```

## 팁

- **오디오 품질**: 배경 소음이 없는 깨끗한 음성이 좋은 결과를 만듭니다.
- **데이터 양**: 최소 10분 이상의 오디오 데이터를 권장합니다.
- **ASR 교정**: ASR 결과의 텍스트를 수동으로 교정하면 학습 품질이 향상됩니다.
- **중지 버튼**: 각 단계에 중지 버튼이 있어 진행 중인 작업을 취소할 수 있습니다.
- **v3/v4 버전**: VRAM을 v1/v2 대비 약 4배 더 사용합니다. 배치 사이즈를 줄이세요.
